# EIKEN Learning App — Roadmap

The roadmap fixes destinations, not implementation order. Small MVPs may pull individual features forward when useful.

## MVP 1 — Vocabulary Core ✅
- Grade 4 vocabulary / phrases
- fixed sets, random tests, review, countability
- local progress, PWA, GitHub Pages

## MVP 2 — Flexible Learning ✅
- 10 / 20 / 30 / 50 / CUSTOM / ENDLESS sessions
- FAST flow mode
- partial-session save
- range filters: priority / category / part of speech
- accepted answers
- near-spelling feedback
- stable IDs in the Excel master
- Excel source → generated Web data

## MVP 3 — Vocabulary Depth
- verified IPA (US / UK)
- pronunciation audio
- example sentences / collocations
- FORM / MEANING / GRAMMAR / USAGE skill profile

## MVP 4 — Vocabulary Expansion
- Grade 4+
- Grade 3 and higher
- shared cross-grade vocabulary master

## MVP 5 — Practice
- independent question database
- vocabulary cloze / grammar / conversation / ordering / reading
- explanations, tags, target vocabulary / grammar IDs

## MVP 6 — Adaptive Learning
- error-pattern analysis
- spaced review
- difficulty / next-question selection

## MVP 7 — EIKEN Simulation
- section-based practice
- timed mock tests
- skill reports
- learning → practice → mock-test loop
